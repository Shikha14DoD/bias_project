# bias_project
Building a state-year panel of US gender bias scores for labor market modeling.

Work-in-progress research project measuring gender bias in US public discourse at state-year resolution. Extends the Garg et al. 2018 PNAS approach (decade-level US-wide bias from word embeddings) to fine-grained state-year cells, with validation against GSS attitudes and Census occupation data. Intended downstream use: input to a labor force participation prediction model with sectoral sub-analyses.
